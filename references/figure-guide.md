# 图表生成指南（数据图红线 · 图表证据卡 · 概念草图边界）

> SKILL.md 红线第 1 条在图形维度的落地：**禁止编造**不只约束正文，更约束图——图内编造数字比正文更隐蔽且难校验。本文件回答三件事：数据图怎么合规生成、概念图（示意图/架构图）AI 做到哪里为止、图怎么登记与校验。

## 1. 两类图，两条路

| 维度 | 数据图（统计图） | 概念图（示意图/架构图/流程图） |
|---|---|---|
| 本质 | 数据的可视化呈现 | 作者的概念判断（体系结构、机制因果） |
| 生成方式 | `generate_figures.py` 从**登记的数据文件**生成 | AI 只产 **Mermaid 文本草稿**；成稿由作者重绘 |
| 红线 | 图只能从数据文件生成，**禁止自编数据点** | 草稿仅供参考，**不入成稿**；不替作者做概念判断 |
| 存放 | `05_图表/数据图/图X-Y.{png,svg,pdf}` | 草稿 `05_图表/草稿/*.mmd`；成稿 `05_图表/定稿/`（作者提供） |

场景提醒：学位论文的图几乎全是数据图（本功能价值最大）；专著大量需要概念图——对概念图要克制，AI 草稿只当脚手架。

## 2. 数据图：五步流程

1. 数据文件就位：放 `02_语料/`（建议 `数据表格/` 子夹；**定稿数据先按台账 §4b 冻结**，图引用其校验和）；
2. 登记图表证据卡：台账 **§3b** 加一行（格式见下）；
3. 生成：`python3 <技能路径>/scripts/generate_figures.py --root . [图号]`（matplotlib 为可选依赖，缺依赖有中文指引；AI 可用 `uv run --with matplotlib` 代跑）；
4. 校验联动：批次收尾跑 validate——正文引用的每个图号须在 §3b 登记（缺→WARN）；数据文件漂移→WARN；
5. 重生成：改数据后重跑脚本即可；**已存在的图默认不覆盖**（防静默覆盖人工后处理过的图），覆盖走 SKILL.md §9 变更单或显式 `--force`。

**§3b 图表证据卡格式**（每图一行，`｜` 分隔）：

```
- 图X-Y｜数据图｜02_语料/数据表格/试验结果.csv｜a1b2c3d4｜{"chart":"bar","x":"方法","y":"精度","title":"各方法精度对比"}｜2026-09-04
- 图X-Y｜概念草图｜05_图表/草稿/图2-1_体系结构.mmd｜-｜Mermaid 草稿（作者定稿前不入正文成图）｜2026-09-04
- 图X-Y｜作者供图｜05_图表/定稿/图3-2_装置照片.tif｜-｜作者提供｜2026-09-04
```

生成配方（JSON）字段：`chart`（bar/line/scatter/box/hist）、`x`/`y`（列名）、`hue`（可选分组列）、`title`、`figsize`（可选）、`bins`（仅 hist）。样式（`dpi`/`format`/`font`）在《书稿配置.json》的 `figure` 块统一配置。

## 3. 概念图：空位＋Mermaid 草稿

1. 正文照常占图号：图题写「**图X-Y（待作者定稿）**」，正文留出引用与解读位置；
2. AI 产 Mermaid **文本草稿**存 `05_图表/草稿/图X-Y_主题.mmd`，文件头加注释行：`%% 概念草图·仅供作者参考重绘·不入成稿`；
3. 草稿同时在 §3b 登记为「概念草图」（来源列填 .mmd 路径，校验和列填 `-`）；
4. 作者以草稿为底重绘出版级图形（Visio/PPT/专业绘图软件），成稿放 `05_图表/定稿/` 并把 §3b 该行更新为「作者供图」。

**边界三条**：草稿不替作者定概念结构（作者可要求改，AI 不坚持）；草稿不进正文与合并稿；AI 不得把草稿渲染成位图冒充成图（渲染需专门工具链，且会固化未定稿的概念）。

## 4. 出版规格速查

- **矢量优先**（SVG/PDF）：线图、柱图缩放不失真，排版首选；
- **位图 ≥300 dpi**：照片类、屏幕截图类；本脚本默认 `dpi: 300`；
- **中文字体**：脚本自动探测 PingFang SC/思源黑体/黑体等；探测失败会提示——出版前统一字体，避免各图字体不一；
- **图题与解读**：每图须有中文图题（`图X-Y 标题`），正文有文字解读（只挂图不解读是常见坑）；数据图的图题下可加"数据来源：作者试验（02_语料/…，冻结 a1b2c3d4）"一行小注。

## 5. 校验与红线索引

- validate：正文引用图号 ↔ §3b 登记核对（缺→WARN"图无证据卡登记"）；数据图来源文件 hash 与登记不符→WARN"数据漂移"（与 §4b 冻结机制同思想）；概念草图 .mmd 缺失→WARN；
- 红线：SKILL.md 第 1 条（禁编造，含图内数据）＋第 2 条（成果四分类——图的数据来源遵守同一分类）；
- 覆盖保护：SKILL.md §9——"生成新图"免审批，"覆盖已有图"走变更单；
- 常见错误速查：`references/troubleshooting.md` 绘图相关条目。
